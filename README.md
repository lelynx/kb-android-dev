# 📚 KB Android Dev – Knowledge Base Server

Une **plateforme de partage de connaissances** pour développeurs Android, permettant de capitaliser et consulter des fiches de connaissance (concepts, snippets, solutions d'erreurs, astuces, etc.).

Le projet se compose de deux volets :
- **Backend** : Serveur Python/FastAPI exposant une API REST
- **Frontend** : Interface web interactive pour consulter et gérer les fiches
- **Bibliothèque Kotlin** : Intégration client pour Android Studio (en développement)

---

## 🎯 Objectif

En tant que développeur Android, pouvoir **enregistrer et consulter des éléments de connaissance** acquis lors de phases de développement, afin de :
- 📖 Capitaliser sur les compétences
- 🔍 Retrouver rapidement des solutions et bonnes pratiques
- 🏗️ Construire une base de connaissances collaboration
